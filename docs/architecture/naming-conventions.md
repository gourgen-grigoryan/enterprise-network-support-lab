# Naming Conventions

## Servers and Virtual Machines

- FW01 - Firewall / Router
- DC01 - Domain Controller
- WIN11-01 - Windows 11 Client
- LNX01 - Linux Server
- MON01 - Monitoring Server
- DB01 - Database Server

## Active Directory

- DNS Domain: corp.lab.node
- NetBIOS Domain: CORP

## User Accounts

Format: firstname.lastname

Examples:
- aram.petrossian
- anna.sargsyan

## Security Groups

Examples:
- GG-IT
- GG-Finance
- GG-HR
