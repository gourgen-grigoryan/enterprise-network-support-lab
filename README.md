# Enterprise Network Support Lab

Hands-on enterprise network and systems administration lab built with Hyper-V.

This project is used to practice and document:

- Windows Server administration
- Active Directory
- DNS and DHCP
- Group Policy
- Windows client support
- Linux administration
- Networking and troubleshooting
- Firewalls, NAT, routing, and VPN
- Monitoring with Zabbix
- Backup and restore
- PostgreSQL and MariaDB/MySQL
- PowerShell and Bash
- Incident troubleshooting

## Current Status

Phase 2: Active Directory, DNS, and DHCP foundation.

FW01 OPNsense firewall/router has been deployed and verified.

DC01 Windows Server 2022 has been deployed as the first domain controller for `corp.lab.node` and is providing Active Directory Domain Services, DNS, and DHCP.
